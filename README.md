Customer Segmentation using RFM Analysis | Power BI Dashboard

📌 Project Overview

This project focuses on Customer Segmentation using RFM (Recency, Frequency, Monetary) Analysis. The objective is to identify different customer groups based on their purchasing behavior and generate actionable business insights for marketing and customer retention.

The dashboard was developed in Power BI using a retail transaction dataset obtained from Kaggle.

---

🎯 Business Objective

- Understand customer purchasing behavior
- Identify high-value and loyal customers
- Detect customers at risk of churn
- Support targeted marketing campaigns
- Improve customer retention strategies

---

📁 Dataset Information

Dataset Source: Kaggle – Online Retail Dataset

The dataset contains transactional retail data with the following fields:

- InvoiceNo
- StockCode
- Description
- Quantity
- InvoiceDate
- UnitPrice
- CustomerID
- Country

Additional Calculated Column

TotalAmount = Quantity × UnitPrice

📊 Dashboard Features

Visualizations

- Monetary by Segment
- Recency by Segment
- Customers by Segment
- Customer Details Table
- Segment Filter (Slicer)

---

📈 Key Insights

- Regular customers contribute 59.87% of total revenue.
- Loyal customers contribute 28.04% of total revenue despite being a smaller customer group.
- Approximately 1,000 customers belong to the Churn Risk segment.
- New customers contribute only 2.37% of total revenue.
- Churn-risk customers show high recency values, indicating a strong opportunity for retention campaigns.
